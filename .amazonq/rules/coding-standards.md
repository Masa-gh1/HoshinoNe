# ほしのね プロジェクト コーディング規約

## 基本方針
- 天体写真処理に特化したビジュアルフローエディタ
- 日本語コメントを使用
- 計算結果精度とパフォーマンスを重視
- 速度が優先される一時的な画面表示は近似値を許可(例:ヒストグラムなど)

## コーディングルール
- クラス名:PascalCase(例:ImageAlignmentNode)
- メソッド名:camelCase(例:detectStars)
- 変数名:camelCase(例:starThreshold)
- 定数:UPPER_CASE(例:BLOCK_SIZE)
- 前後の行で = : , の位置揃えを行う
- 複数行に跨る () [] {} の位置揃えを行う
- 条件文は == <= < を用いることを原則とする
- 条件文で == の片辺が定数の場合、定数を左辺にすることを原則とする
- if elif else の分岐内で代入 が在る場合、すべての分岐で同じ変数を更新する
- 関数先頭付近を除き、 if elif else の分岐内で retuen が在る場合、すべての分岐で retuen を行うこと
- 関数は一般化を主とし、単なる処理の分割には使わない

## データ型
- FlowData に保存する型を決定する為、numpy での一部での処理について numpy_helpers を用意しているのでこれを用いる

## ドキュメント
- 全メソッドに日本語 docstring を記述
- 複雑なアルゴリズムには詳細コメント
- パラメータの単位を明記(px, %, 度など)

## エラーハンドリング
- 原則として例外を捕まえて消し去ることは禁止
- ライブラリ内からのワーニングを隠蔽することは禁止
- 標準ライブラリ以外への依存機能は可用性チェック
- ユーザーフレンドリーなエラーメッセージ
- 設定値の妥当性検証
